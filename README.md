# Spin the Wheel

A tiny, playful decision wheel built as a static web app.

## Features

- Add, edit, remove and shuffle options
- Smooth animated wheel spin
- Winner reveal + confetti
- Local browser persistence with `localStorage`
- Light and dark modes
- Responsive mobile layout
- No backend, no uploads, no build step

## Cloudflare Pages

Deploy directly from the repository:

- **Production branch:** `main`
- **Framework preset:** None
- **Build command:** leave blank
- **Build output directory:** `/` (repository root)

Cloudflare Pages can serve `index.html` and the static assets directly.
